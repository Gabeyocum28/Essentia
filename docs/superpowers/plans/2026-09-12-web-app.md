# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React + TypeScript web app at `https://essentia.gabeyocum.com/` with the same flow as the iOS app (search → seed → recommendations → insights, with a persistent player), served by the API container.

**Architecture:** `web/` is a Vite project with no UI framework. A typed `api.ts` mirrors `APIClient.swift`. Screens are plain React components; visualizations draw on `<canvas>` with the same styling the iOS Canvas views use. The production build is produced in a Node stage of `deploy/Dockerfile` and copied to `/app/web/dist`, which FastAPI serves at `/` with a single-page fallback; API routes are unchanged and still win. In development the Vite dev server proxies `/api` to the live VM.

**Tech Stack:** Node 22, Vite 6, React 18, TypeScript 5, Vitest (unit tests, jsdom); Python side: FastAPI `StaticFiles`.

**Spec:** `docs/superpowers/specs/2026-09-11-oracle-atlas-migration-design.md`, section 7.

## Global Constraints

- The web app calls the API only through relative `/api/...` URLs (Caddy strips the prefix in production; Vite proxies in dev). Audio plays from `/api/preview/{track_id}` via `<audio>` (the server 302s to a fresh Deezer URL).
- Every API type in `web/src/api/types.ts` matches the server's JSON exactly (shapes listed under "Facts"). No field the server no longer sends (`groove`, `genre`, `parts`, `weights`) is modelled.
- Dark theme only, mirroring iOS: black canvases, white dots at 55% for the corpus, accent blue `#0A84FF` for recs/selection/controls, yellow `#FFD60A` for the seed, walk path and threshold cursor, cyan `#64D2FF` for histogram bars and barcode, red for errors. Numbers and formulas in a monospace font. Artwork as 8px-radius squares.
- Axes come from `GET /api/axes`; never hardcode them.
- Out of scope (say so in the UI with a short note, do not stub): the client-side mel spectrogram, self-similarity matrix, and band-solo playback (the iOS "SOUND" mode).
- Branch `web-app` off `main`. Python: `python3 -m pytest -q` green before every commit. Web: `npm test` and `npm run build` green before every commit that touches `web/`.
- `web/node_modules` and `web/dist` are gitignored and dockerignored; the Docker build installs and builds from `package-lock.json`.
- `CORPUS_CAP` default lowered to 10000 in `deploy/.env.example` (the /viz endpoints hold a dense n×n pairwise matrix; 10k is the ceiling the viz code documents).

## Facts (do not re-derive)

Server routes (all under `/api` publicly): `GET /search?q=` → `{results: Track[]}`; `POST /seed {track_id}` → `{track_id, status: "ready"|"unanalyzed"}` (blocking up to ~20 s; 404 unknown track; 502 `{"detail":"analysis failed"}`); `GET /axes` → `{axes: {id,label}[]}`; `GET /recommend?track_id&axis&limit=10` → `{seed_track_id, axis, results: (Track & {score:number})[]}`; `GET /preview/{id}` → 302.
`Track = {track_id: string, title, artist, album: string, artwork_url: string, preview_url: string, score?: number}`.
Viz: `GET /viz/map?track_id&axis&limit=10[&correction=on|off]` → `{points:{ids:string[], x:number[], y:number[], tracks:Track[]}, seed: Track&{x,y}, recs:(Track&{score,x,y, math:{metric:string, dot:number, seed_norm:number, rec_norm:number, distance?:number, centrality?:number}})[], axis:{id:string, metric:string, direction:number}}`; `GET /viz/walk?from&to&k=8` → `{path:(Track&{x,y})[], geodesic:number, ambient:number, detour:number, k:number}`; `GET /viz/histogram?track_id` → `{bins:number[], counts:number[], rec_scores:number[], percentile:number, null:{mean:number, sd:number}, corpus:{mean:number, sd:number}}`; `GET /viz/hubs?k=8&limit=` → `{hubs:(Track&{count:number})[], central:(Track&{centrality:number})[], isolated:(Track&{centrality:number})[], expected_k:number, all_counts:{track_id,count}[]}`; `GET /viz/tour` → `{ids:string[], coords8: string (base64 little-endian float32, n×8 row-major), variance:number[8]}`; `GET /viz/mst` → `{ids:string[], edges:[number,number,number][]}` ascending by distance; `GET /viz/extremes?pc=1..8&limit=4` → `{pc, variance_pct, low:Track[], high:Track[]}`; `GET /viz/attribute?seed&rec` → `{status:"pending"|"ready"|"failed", base?:number, bands?:{lo_hz,hi_hz,delta}[], error?:string}` (poll every 1.5 s, give up after 60 s).
iOS drawing rules to mirror: galaxy = 1.5px white 55% dots for corpus, accent spokes seed→rec, recs 4.5px accent (11px halo when selected), seed yellow glow; zoom 1–8 with wheel/pinch, drag pan, click = nearest point within 36px. Topology = MST edges with d ≤ threshold drawn faint white, dots coloured by component-rank hue `(rank % 12)/12`, sat 0.72, light 0.60; singletons white 25%; barcode strip of edge "deaths" in cyan with a yellow threshold cursor. Tour = 8-D coords projected through a 2-frame from 28 chained Givens rotations at speeds `0.05·√prime_k`, radius fixed to max L2 norm, white 2.4px dots, play/pause, caption "top-8 PCs hold X% of variance". Proof = cyan bars over similarity −1…1, white Gaussian null `total·binWidth·pdf(x; 0, sd)`, yellow ticks at rec scores, correction toggle refetching `/viz/map?axis=surprise&correction=`. Why-similar = one bar per band, height `max(delta,0)/peak`, tallest full accent, others 45%, labels like "240 / 1.2k".
Vite: `server.proxy = {"/api": {target: "https://essentia.gabeyocum.com", changeOrigin: true}}`.
`app.py` has `@app.get("/")` returning a JSON signpost; it is removed (not in the contract; `tests/server/test_app.py` has a test for it to delete). FastAPI matches declared routes before a mounted `StaticFiles`, and a catch-all SPA route must be declared last.

`web/src/api/client.ts`:

```ts
import type * as T from "./types";

export class ApiError extends Error {
  constructor(public status: number, public detail: string) { super(`${status}: ${detail}`); }
}

const BASE = "/api";

async function request<R>(path: string, init?: RequestInit): Promise<R> {
  const res = await fetch(BASE + path, { headers: { "content-type": "application/json" }, ...init });
  if (!res.ok) {
    let detail = res.statusText;
    try { detail = (await res.json()).detail ?? detail; } catch { /* non-JSON error body */ }
    throw new ApiError(res.status, detail);
  }
  return res.json() as Promise<R>;
}

const q = (params: Record<string, string | number | undefined>) =>
  "?" + new URLSearchParams(Object.entries(params).filter(([, v]) => v !== undefined)
    .map(([k, v]) => [k, String(v)])).toString();

export const previewUrl = (trackId: string) => `${BASE}/preview/${trackId}`;

export function decodeCoords8(b64: string, n: number): Float32Array[] {
  const bytes = Uint8Array.from(atob(b64), (c) => c.charCodeAt(0));
  const all = new Float32Array(bytes.buffer, bytes.byteOffset, n * 8);
  return Array.from({ length: n }, (_, i) => all.subarray(i * 8, i * 8 + 8));
}

export const api = {
  search: (query: string) => request<{ results: T.Track[] }>(`/search${q({ q: query })}`),
  seed: (track_id: string) => request<T.SeedResponse>("/seed", { method: "POST", body: JSON.stringify({ track_id }) }),
  axes: () => request<{ axes: T.Axis[] }>("/axes"),
  recommend: (track_id: string, axis: string, limit = 10) =>
    request<T.RecommendResponse>(`/recommend${q({ track_id, axis, limit })}`),
  vizMap: (track_id: string, axis: string, limit = 10, correction?: "on" | "off") =>
    request<T.VizMap>(`/viz/map${q({ track_id, axis, limit, correction })}`),
  vizWalk: (from: string, to: string, k = 8) => request<T.VizWalk>(`/viz/walk${q({ from, to, k })}`),
  vizHistogram: (track_id: string) => request<T.VizHistogram>(`/viz/histogram${q({ track_id })}`),
  vizHubs: () => request<T.VizHubs>("/viz/hubs"),
  vizTour: async (): Promise<T.VizTour> => {
    const raw = await request<{ ids: string[]; coords8: string; variance: number[] }>("/viz/tour");
    return { ids: raw.ids, coords: decodeCoords8(raw.coords8, raw.ids.length), variance: raw.variance };
  },
  vizMst: () => request<T.VizMst>("/viz/mst"),
  vizExtremes: (pc: number, limit = 4) => request<T.VizExtremes>(`/viz/extremes${q({ pc, limit })}`),
  vizAttribute: (seed: string, rec: string) => request<T.VizAttribution>(`/viz/attribute${q({ seed, rec })}`),
};
```

```python
# ---- the web app: web/dist built into the image, served at / ----
# Declared last so every API route above wins; unknown GET paths without a
# file extension fall back to index.html for client-side routing.
WEB_DIST = Path(os.environ.get("WEB_DIST", str(Path(__file__).resolve().parents[3] / "web" / "dist")))


def _spa_index() -> FileResponse:
    index = WEB_DIST / "index.html"
    if not index.exists():
        raise HTTPException(404, "web app not built")
    return FileResponse(index)


if (WEB_DIST / "assets").is_dir():
    app.mount("/assets", StaticFiles(directory=WEB_DIST / "assets"), name="assets")


@app.get("/", include_in_schema=False)
def spa_root() -> FileResponse:
    return _spa_index()


@app.get("/{path:path}", include_in_schema=False)
def spa_fallback(path: str) -> FileResponse:
    if "." in path.rsplit("/", 1)[-1]:
        file = WEB_DIST / path
        if file.is_file():
            return FileResponse(file)
        raise HTTPException(404)
    return _spa_index()
```
